# 메인 창 (리포트·설정)

메인 창은 `PyeobugiMac/MainWindow/`에 있다. 모든 화면은 1280×832 고정 레이아웃이다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `MainWindow.swift` | `NSWindow` 호스팅, 화면 전환(`screen`), 사이드바, 감지 타이머, 공용 흰 카드(`Card`) |
| `ReportScreen.swift` | `ReportState`(불러오는 중, 기록 없음, 오류)를 받아 그린다 |
| `SettingsScreen.swift` | 설정 화면, 토글(`PillToggleStyle`), 교정 강도 3단 슬라이더 |

## 창

| 항목 | 값 |
| --- | --- |
| 내용 크기 | 1280×832, 최소 크기도 같다 |
| 창을 키울 때 | 1280×832 덩어리를 가운데에 두고, 남는 곳은 main5 배경 |
| 제목 막대 | macOS 표준, 제목 "펴부기" |
| 창을 닫을 때 | 창을 남겨 두고 숨기기만 한다. 화면과 사이드바 접힘 상태는 앱을 끌 때까지 유지 |

창을 여는 곳:

| 계기 | 화면 |
| --- | --- |
| 온보딩을 마친 상태로 앱 실행 | 리포트 |
| 온보딩 완료 안내에서 "시작하기" | 리포트 |
| 메뉴 막대 "펴부기 열기" | 마지막 화면 |
| 실행 중에 Dock 아이콘 클릭, Finder 등에서 다시 실행 (`applicationShouldHandleReopen`) | 열린 창이 있으면 그 창을 앞으로, 없으면 메인 창의 마지막 화면 |

창이 열려 있는 동안만 Dock과 Cmd+Tab에 앱이 보이고, 마지막 창을 닫으면 메뉴 막대 전용으로 돌아간다 (`docs/architecture.md` Dock 아이콘). 창을 열 때는 `bringToFront()`로 다른 앱이 앞에 있어도 맨 앞의 키 창으로 만든다.

## 레이아웃

| 항목 | 펼침 | 접힘 |
| --- | --- | --- |
| 사이드바 폭 | 240 | 80 |
| 본문 폭 | 976 | 1140 |

- 사이드바 바깥 여백: 위·아래 16, 왼쪽 16, 오른쪽 24
- 본문 열: 제목과 카드 사이 간격 21, 창 높이 안에서 세로 가운데

## 사이드바

| 항목 | 값 |
| --- | --- |
| 크기 | 높이 805, 안쪽 여백 가로 16·세로 36, 둥근 모서리 12, main1 |
| 로고 | 펼침 116×30(`Logo`), 접힘 36×30(`LogoSymbol`), 메뉴와 간격 32 |
| 메뉴 탭 | 높이 48, 안쪽 여백 8, 아이콘 24, 아이콘·글자 간격 12, 탭 사이 8. 접히면 48×48. 선택되면 main2 배경, labelBold. 글자·아이콘 grey200 |
| 감지 시작 버튼 | 높이 44, 안쪽 여백 10, main5, 둥근 모서리 6, labelBold grey900, 재생 아이콘 14 main1. 접히면 44×44 아이콘만 |
| 감지 중 | 일시정지 버튼 44×44, 경과 시간(heading, 흰색, `HH:MM:SS`), 종료 버튼 44×44. 접히면 일시정지 버튼만 |
| 접기·펼치기 | 사이드바의 빈 곳을 누르면 바뀐다. 메뉴와 감지 버튼 영역은 눌러도 바뀌지 않는다. 애니메이션 없음 |

감지 경과 시간은 `PostureMonitor`가 메모리에만 둔다. 일시정지(`stop`)는 쌓인 시간을 남겨 두고 "자세 감지 시작" 버튼으로 돌아가며, 다시 시작하면 이어서 센다. 종료(`end`)는 감지를 멈추고 0으로 돌린다. 메뉴 막대의 "감지 정지"는 일시정지와 같다.

## 공용 카드

흰색, 안쪽 여백 16, 둥근 모서리 12, 내용 간격 24, 그림자 `(4, 4)` 흐림 반경 8, 색 `#1A282E` 5%.

## 리포트

- 제목 "자세 리포트"(title)
- 상태 카드: 높이 699, 내용 가운데, 간격 24

| 상태 | 그림 | 문구 |
| --- | --- | --- |
| 불러오는 중 | `Spinner` | "기록을 불러오는 중..." (heading), 간격 16 |
| 기록 없음 | `ReportEmpty` 300×300 | "아직 기록이 없어요" (heading), "자세 감지를 시작하고, 펴부기와 함께 기록을 쌓아가봐요!" (body, grey500), 간격 8 |
| 오류 | `ReportError` 300×404 (와이파이 표시 포함) | "기록을 불러올 수 없어요", 연결이 끊긴 경우와 그 밖의 경우 안내 두 가지, "다시 시도" 버튼 |

화면은 `ReportState`만 받아 그리고, 저장소나 네트워크는 모른다. 지금은 창이 항상 `.empty`를 넘긴다. 데이터가 있는 상태와 날짜 선택은 로컬 리포트 단계에서 추가한다.

## 설정

- 제목 "설정"(title)
- "자세 교정" 카드
  - 교정 강도: 제목과 설명, 슬라이더 간격 24
  - 기준 자세: "기준 다시 잡기" 버튼이 기준 잡기 창을 연다. 카메라 권한이 없으면 비활성
- "기능" 카드: 공부 타이머, 스트레칭 알림, 거북이 오버레이 표시, 전체 화면에서도 표시
- 항목 제목은 bodyBold grey900, 설명은 label grey700, 둘 사이 간격 4

설정 값은 `TurtleOverlay`의 속성(`UserDefaults` 키는 `docs/architecture.md`)에 바인딩한다. 메뉴 막대도 같은 인스턴스를 쓰므로 어느 쪽에서 바꿔도 바로 반영된다.

| 부품 | 값 |
| --- | --- |
| 토글 | 52×30 캡슐, 켜짐 main2·꺼짐 grey300, 손잡이 흰색 24(안쪽 3), 0.2초 ease-in-out |
| 교정 강도 슬라이더 | 트랙 높이 8 grey300, 채움 높이 9 main3, 손잡이 16(흰색, main3 테두리 2), 단계 이름과 간격 12. 끌기·트랙 클릭·단계 이름 클릭·좌우 방향키로 바꾸고 0.15초 ease-out으로 옮긴다. 선택한 단계까지의 이름은 labelBold grey900, 나머지는 label grey700. 단계 이름은 느슨하게·보통·엄격하게 |

## 글꼴과 색

- 글꼴은 앱 전체가 Pretendard(Regular·Medium·SemiBold, 1.3.9)다. `Info.plist`의 `ATSApplicationFontsPath`로 앱을 시작할 때 등록한다.
- 글자 스타일(`TextStyle`, `PyeobugiMac/Onboarding/OnboardingUI.swift`):

| 스타일 | 크기 | 굵기 | 줄 높이 | 자간 |
| --- | --- | --- | --- | --- |
| title | 34 | Medium | 1.3 | −0.03em |
| heading | 24 | Medium | 1.3 | −0.02em |
| body / bodyBold | 16 | Regular / SemiBold | 1.5 | 0 |
| label / labelBold | 14 | Regular / SemiBold | 1.4 | 0 |

- 색은 `Color`의 main1~5, grey100~900 토큰을 쓴다.
