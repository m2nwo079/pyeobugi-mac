# 거북이 오버레이

주 화면 `visibleFrame` 전체를 덮는 클릭 통과 `NSPanel` 위에서 거북이가 화면 맨 아래를 좌우로 돌아다니고, 자세가 나빠지면 목을 늘인다.
창 설정은 `docs/architecture.md`의 "오버레이 기본 설정"을 따른다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `PyeobugiMac/Overlay/TurtleModel.swift` | 동작 상수, 행동 루프, 목 길이, 프레임마다 그릴 값 계산 |
| `PyeobugiMac/Overlay/TurtleShapes.swift` | 여섯 모습과 긴 목을 그리는 SwiftUI 도형 |
| `PyeobugiMac/Overlay/TurtleOverlay.swift` | 패널 생성, 메뉴 토글, 자세 → 목 길이 연결 |

## 동작 요약

- 행동 루프는 `MainActor`의 `Task` 하나가 순서대로 실행한다. 대기는 `Task.sleep`, 그리기는 `TimelineView(.animation)`이 시각으로부터 계산한다.
- 매 루프 난수 하나를 뽑는다. 정면을 보고 있고 0.14 미만이면 머리 털기, 정면이 아니고 0.32 미만이면 정면 돌아보기(그 뒤 0.4 확률로 머리 털기), 나머지는 걷기.
- 걷기 목표: 0.45 확률로 좌우 ±0.3 rad, 아니면 아무 방향. 거리는 크기의 0.8~2.4배, 바닥이 한 줄이라 가로 성분만 남는다. 크기의 0.6배보다 가까우면 다시 뽑고, 20번 실패하면 화면 가운데로 간다.
- 걷는 속도는 출발부터 도착까지 일정하다 (크기 × 0.55 / 초). 통통 튀는 움직임은 0.9초 주기의 뒤뚱(위로 6pt, ±2°)과 다리 흔들기로 나온다.
- 방향 전환은 여덟 방향(왼쪽 → 앞왼쪽 → 정면 → 앞오른쪽 → 오른쪽 → 뒤오른쪽 → 뒤 → 뒤왼쪽)을 가까운 쪽으로 한 칸씩 지난다. 정반대일 때는 0.75 확률로 정면을 지나는 쪽을 고른다. 오른쪽 계열은 왼쪽 그림의 거울상이다.
- 목 늘이기는 다른 행동보다 우선한다. 대기 중이면 바로 끊고, 걷는 중이면 그 자리에서 멈춘다. 이미 시작한 방향 전환과 머리 털기는 끝까지 한다.
- 목을 늘일 때는 가장 가까운 옆모습으로 돈 뒤 살짝 웅크렸다가 스프링으로 목표 길이를 따라간다. 머리가 화면 위로 나가면 옆 칸 아래에서 다시 올라온다. 칸은 얼굴 쪽 가까운 칸부터 쓰고, 끝에 닿으면 반대편 끝에서 안쪽으로 이어 간다.
- 목 길이는 `PostureCore`의 `neckLength`(기본 교정 강도)로 계산한다. 자세 확인 중(`pendingBad`)으로 처음 본 후보 시각을 붙잡아 두고 확정(`bad`) 뒤에도 유지하며, 바른 자세·회복 중·얼굴 없음이 되면 버린다.
- 시스템의 "동작 줄이기"가 켜져 있으면 자율 행동과 모든 반복 움직임을 하지 않는다. 목은 돌기·스프링 없이 가장 가까운 옆모습으로 바꾼 뒤 길이만 바로 반영한다.
- 메뉴의 "거북이 표시"(`UserDefaults` 키 `showTurtle`, 기본 켜짐)를 끄면 패널을 닫고, 다시 켜면 처음 상태로 새로 만든다.

## 상수

시간은 모두 초 단위다. 길이 단위 "크기"는 거북이 그림 한 변의 길이, "그림 단위"는 그림 한 변을 500으로 나눈 길이다.

### 크기와 바닥

| 항목 | 값 |
| --- | --- |
| 크기 | `max(80, min(120, 화면 너비 × 0.3, 화면 높이 × 0.3))` pt |
| 바닥 (발끝 높이) | 화면 아래에서 8 pt 위 |
| 발끝 위치 | 그림 높이의 0.8 |
| 시작 위치 | 화면 왼쪽 끝, 정면 |

### 자율 행동

| 항목 | 값 |
| --- | --- |
| 시작 대기 | 0.9 |
| 대기 중 확인 간격 | 0.04 |
| 머리 털기 확률 (정면일 때) | 0.14 |
| 정면 돌아보기 확률 (정면이 아닐 때, 누적) | 0.32 |
| 정면 돌아본 뒤 머리 털기 확률 | 0.4 |
| 머리 털기 뒤 대기 | 0.7~1.6 |
| 정면 돌아본 뒤 대기 | 0.9~1.6 |
| 그 뒤 머리 털기 후 대기 | 0.6~1.2 |
| 그 뒤 머리를 털지 않을 때 대기 | 0.5~1.2 |
| 걷기 뒤 대기 | 0.6~2.2 |
| 목을 넣은 뒤 대기 | 0.7 |

### 걷기

| 항목 | 값 |
| --- | --- |
| 속도 | 크기 × 0.55 / 초, 가감속 없음 |
| 옆으로 걷기 비중 | 0.45 (좌우 ±0.3 rad) |
| 거리 | 크기 × 0.8~2.4 |
| 최소 이동 거리 | 크기 × 0.6 |
| 목표 재시도 | 20회 |
| 멈춤 확인 간격 | 1/60 |
| 뒤뚱 주기 | 0.9 (위로 6 pt, ±2°) |
| 다리 흔들기 | 0.9 주기, ±11°, 7 pt 들기, 뒷다리는 0.45 늦게 |
| 꼬리·머리 흔들기 | 0.45마다 왕복 (꼬리 ±8°, 머리 ±1.5°·3 pt) |
